Siftdog's code is open source under the [MIT License](LICENSE). You can use, modify, host
and sell it. The **name "Siftdog"** and any Siftdog logos are trademarks of the project's
maintainer ([@khsarvar](https://github.com/khsarvar)), and the MIT License doesn't grant rights
to them.

This policy exists so that people can tell whether they're using the official project. It
isn't meant to restrict what you do with the code.

## You can, without asking

- Say truthfully that your product uses, works with, or is based on Siftdog, for example
  "built on Siftdog" or "a fork of Siftdog".
- Redistribute **unmodified** Siftdog releases under the Siftdog name.
- Write articles, tutorials, videos, talks and comparisons that mention Siftdog.
- Use the name for non-commercial community groups and events, as long as they don't suggest
  they're run or endorsed by the project.

## Please ask first

- Naming a product, service, company, package or hosted API "Siftdog", or anything
  confusingly similar (such as "Siftdog Cloud" or "SiftDog Pro").
- Distributing a **modified** version under the Siftdog name. Forks should use a different
  name; "based on Siftdog" is fine.
- Using "Siftdog" in a domain name, or using a Siftdog logo in a way that suggests the
  project endorses or partners with you.

## Questions and permission

Open an issue at <https://github.com/khsarvar/siftdog/issues> or contact
[@khsarvar](https://github.com/khsarvar). If you're unsure whether something is allowed, ask;
reasonable requests are usually approved.
